Confidentialité

En bref

Rien n'est collecté. Il n'y a pas de compte, pas de cookie, pas de mesure d'audience et pas de publicité. Le message est dessiné dans ton navigateur et n'est envoyé nulle part.

Aucun prénom d'enfant

Le site ne demande jamais le prénom d'un enfant. Si tu en écris un dans le message, il reste sur ton appareil.

Ce que garde ton navigateur

Pour te faire gagner du temps d'un jour à l'autre, ton navigateur garde sur ton appareil :

  • les noms de tes lutins favoris, ton dernier message et tes réglages (stockage local du navigateur) ;
  • les polices que tu importes (base de données locale du navigateur).

Ces données ne quittent pas ton appareil. Pour les effacer, supprime les données de ce site dans les réglages de ton navigateur.

Polices

Les polices sont hébergées sur le site lui-même : aucune requête n'est envoyée à un service tiers (Google Fonts ou autre).

Hébergement

Le site est hébergé par GitHub Pages. Comme tout hébergeur, GitHub peut enregistrer des données techniques de connexion (comme l'adresse IP) pour assurer la sécurité du service. Voir la déclaration de confidentialité de GitHub.
