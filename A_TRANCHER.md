# À trancher

Choix provisoires posés pour avancer ; à valider en bloc ou à changer.

1. **Nom du produit et domaine** (bloquant avant d'en parler autour de soi : les favoris enregistrés sont liés à l'adresse du site). Domaines libres vérifiés le 26/11 : `lutin.fun`, `lutins.fun`, `motsmagiques.fun`, `lutins.christmas`, `motdelutin.fr`, `lemotdulutin.fr`.
   Reco : **lutin.fun** (court, pas limité à Noël). Le titre affiché est provisoirement « Lutin ».
2. **Identité visuelle de l'interface** : provisoire = fond papier crème, rouge Noël, titres en Fredoka, icône sapin rouge. Options : a) garder ; b) planche de 3 propositions.
3. **Noms des univers** : Journée Grognon, Académie de Magie, Idoles contre les Ombres, Chiots Sauveteurs, Héros Araignée. Reco : garder (génériques, reconnaissables).
4. **Réglages par défaut** : couleur par lettre, effet main activé, habillage « Sapins » dans les coins, sans cadre, taille automatique. Reco : garder.
5. **Texte d'exemple** du premier lancement : « Coucou les enfants ! Cette nuit, nous avons préparé une petite surprise… Saurez-vous la trouver avant le petit-déjeuner ? » signé « Lutin Farceur ». Reco : garder.
6. **Contact des mentions légales** : la page Issues du dépôt GitHub (pas d'e-mail publié). Options : a) Issues ; b) une adresse e-mail dédiée.
7. **Licence du code** : provisoire « tous droits réservés » (comme Classic or Not). Options : a) garder ; b) licence libre (MIT).
8. **Alloy Ink** : demander une licence web au designer (wepfont) pour l'intégrer au site ? Reco : non pour l'instant, l'import par le parent suffit.
